# __NAME__

Tailwind 4 sandbox. The package is installed here, not in a parent folder. Configuration lives in `src/styles.css` (`@import "tailwindcss"`). Do not add a Tailwind or PostCSS config above this directory.

Default port is 5199. Change it in `package.json` and `vite.config.ts` if you need another port, then record it in `PORTS.md`.

```powershell
pnpm install
pnpm dev
```
